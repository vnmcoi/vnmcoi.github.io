Bài toán yêu cầu in ra chuỗi Hello, World!. Ta có thể sử dụng cout trong C++ để thực hiện thao tác này.

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve(void)
{
    cout << "Hello, World!";
}

int main(void)
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```
